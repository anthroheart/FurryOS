💾 CACHE POLICY (ALL MODES)
═══════════════════════════════════════════════════════════════════

Default: NO CACHE

Rationale:
  "Modern fast internet (50+ Mbps) makes aggressive caching
   unnecessary. Disabling caches improves privacy, reduces disk
   usage, and ensures you always have fresh content."

Options:
  1. No Cache (Default)
     • Zero browser/application caching
     • /tmp mounted as tmpfs (RAM-based)
     • Maximum privacy

  2. Minimal Cache
     • Session-only caching
     • Auto-clear on browser exit
     • Good for slow connections

  3. Standard Cache
     • Traditional caching (500MB limit)
     • For offline/mobile use

🚀 QUICK START

1. Make Scripts Executable:
   chmod +x build_furryos_gen2.1_enhanced.sh
   chmod +x FurryOS_Live_Multimedia_Setup_Post_ISO_Gen2.1.sh

2. Add Your Assets:
   payload/assets/wallpapers/default.jpg
   payload/assets/splash/splash.png
   payload/assets/sounds/startup.ogg

3. Build:
   Option A: sudo ./build_furryos_gen2.1_enhanced.sh
   Option B: python3 FurryOS_Gen2.1_Builder_GUI.py

4. Test:
   qemu-system-x86_64 -cdrom _generated/output/furryos-gen2.1-final-amd64.iso -m 2G

5. Deploy:
   sudo dd if=_generated/output/furryos-gen2.1-final-amd64.iso of=/dev/sdX bs=4M status=progress

✨ WHAT HAPPENS ON LIVE BOOT
═══════════════════════════════════════════════════════════════════

1. Plymouth shows your splash.png during boot
2. User logs into MATE desktop
3. Auto-setup script runs (invisible to user):
   • Creates ~/FurryOS folder
   • Copies all assets from ISO
   • Sets wallpaper to default.jpg
   • Plays startup.ogg sound
   • Places desktop files on Desktop
   • Adds FurryOS to file manager sidebar
   • If Ghost mode: Randomizes MAC/hostname
4. User sees fully configured desktop
5. Mode switcher available in Settings menu
