🔴 CRITICAL: FILENAME RULES
═══════════════════════════════════════════════════════════════════════════════

⚠️  ALL FILENAMES ARE CASE-SENSITIVE ON LINUX!

✅ CORRECT FILENAMES (MUST USE EXACTLY):
   default.jpg
   splash.png
   startup.ogg
   shutdown.ogg

❌ WRONG FILENAMES (WILL NOT WORK):
   Default.jpg           ← Capital D
   DEFAULT.JPG           ← All capitals
   wallpaper.jpg         ← Wrong name
   splash.PNG            ← Capital extension
   StartUp.ogg           ← Capital letters
   startup.mp3           ← Wrong format (must be .ogg)
   startup.ogg.bak       ← Wrong name

REMEMBER: Linux treats these as DIFFERENT files:
  default.jpg ≠ Default.jpg ≠ DEFAULT.JPG

ALWAYS use lowercase filenames!

📋 ASSET SPECIFICATIONS
═══════════════════════════════════════════════════════════════════════════════

WALLPAPER (default.jpg):
  ├─ Format: JPEG
  ├─ Size: 1920×1080 MINIMUM (higher OK: 2560×1440, 3840×2160)
  ├─ Location: ~/FurryOS/sourcecode/payload/assets/wallpapers/
  ├─ Convert: convert image.png default.jpg
  └─ Purpose: Desktop background

SPLASH (splash.png):
  ├─ Format: PNG
  ├─ Size: 1024×768 OR 1920×1080
  ├─ Location: ~/FurryOS/sourcecode/payload/assets/splash/
  ├─ Convert: convert image.jpg splash.png
  └─ Purpose: Boot screen (shown during startup)

STARTUP SOUND (startup.ogg):
  ├─ Format: OGG Vorbis
  ├─ Duration: 2-5 seconds
  ├─ Bitrate: 128 kbps or higher
  ├─ Location: ~/FurryOS/sourcecode/payload/assets/sounds/startup/
  ├─ Convert: ffmpeg -i sound.mp3 -codec:a libvorbis -q:a 5 startup.ogg
  └─ Purpose: Login sound (plays when user logs in)

SHUTDOWN SOUND (shutdown.ogg) - OPTIONAL:
  ├─ Format: OGG Vorbis
  ├─ Duration: 2-5 seconds
  ├─ Location: ~/FurryOS/sourcecode/payload/assets/sounds/shutdown/
  ├─ Convert: ffmpeg -i sound.mp3 -codec:a libvorbis -q:a 5 shutdown.ogg
  └─ Purpose: Logout sound (optional, plays during shutdown)
