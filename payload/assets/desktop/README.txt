🐾 ABOUT FURRYOS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
FurryOS Gen2 is a Debian-based Linux distribution designed for
the furry community. Built on MATE desktop with multimedia tools,
creative software, and a friendly user experience.

Author: Anthro Teacher
Organization: Anthro Entertainment LLC
License: MIT


📦 YOU ARE RUNNING IN LIVE MODE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Nothing you do right now will be saved unless you install FurryOS
to your hard drive. This is a "try before you install" environment.

• Test hardware compatibility
• Explore the desktop environment
• Connect to WiFi and browse the web
• Run the installer when ready


🚀 TO INSTALL FURRYOS
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
Double-click the "Install FurryOS Gen2" icon on your desktop.
Follow the installation wizard to set up FurryOS permanently.

⚠️  IMPORTANT: Back up your data before installing!


🎨 WHAT'S INCLUDED
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
• MATE Desktop Environment (lightweight and fast)
• Firefox ESR web browser
• LibreOffice office suite
• GIMP image editor
• Multimedia tools (music, video, art)
• Custom wallpapers and themes
• AnthroHeart Universe content (optional)
