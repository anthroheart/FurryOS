PUT CUSTOM APPLICATION ICONS HERE (OPTIONAL)

OPTIONAL FILES:
  • Application icons (PNG or SVG)
  • Menu icons
  • System tray icons
  • Folder icons
  • File type icons

SPECIFICATIONS:
  • Formats: PNG, SVG (PNG for raster, SVG for vector)
  • Common sizes: 16x16, 22x22, 24x24, 32x32, 48x48, 64x64, 128x128, 256x256
  • Any filenames (lowercase recommended)

PURPOSE:
  Custom icons for applications, menus, system components.
  These are OPTIONAL and depend on your customization level.

EXAMPLES:
  ✅ furryos-logo.svg          (Main FurryOS logo - scalable)
  ✅ furryos-logo-48.png       (48x48 raster version)
  ✅ furryos-logo-256.png      (256x256 high-res version)
  ✅ file-manager.png          (Custom file manager icon)
  ✅ web-browser.png           (Custom browser icon)

ICON THEMES:
  You can organize icons into theme folders:
  • icons/furryos-theme/apps/
  • icons/furryos-theme/places/
  • icons/furryos-theme/actions/

NOTES:
  • This folder is completely optional
  • Standard freedesktop.org icon naming is recommended
  • SVG icons scale better than PNG
