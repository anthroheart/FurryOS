🎯 QUICK START (5 Steps)
═══════════════════════════════════════════════════════════════════

1. Create Folders
   $ mkdir -p ~/FurryOS/sourcecode/payload/assets/{wallpapers,splash,sounds/{startup,shutdown}}

2. Copy Build Scripts
   $ cp GENOME_Gen2.1_Final.yaml ~/FurryOS/sourcecode/
   $ cp build_furryos_gen2.1_enhanced.sh ~/FurryOS/sourcecode/
   $ cp FurryOS_Live_Multimedia_Setup_Post_ISO_Gen2.1.sh ~/FurryOS/sourcecode/
   $ chmod +x ~/FurryOS/sourcecode/*.sh

3. Add Your Assets
   $ cp my_wallpaper.jpg ~/FurryOS/sourcecode/payload/assets/wallpapers/default.jpg
   $ cp my_splash.png ~/FurryOS/sourcecode/payload/assets/splash/splash.png
   $ cp my_startup.ogg ~/FurryOS/sourcecode/payload/assets/sounds/startup/startup.ogg

4. Build Your ISO
   $ cd ~/FurryOS/sourcecode
   $ sudo ./build_furryos_gen2.1_enhanced.sh

   (Or use GUI: python3 FurryOS_Gen2.1_Builder_GUI.py)

5. Test or Deploy
   Test: qemu-system-x86_64 -cdrom _generated/output/furryos-gen2.1-final-amd64.iso -m 2G
   USB:  sudo dd if=_generated/output/furryos-gen2.1-final-amd64.iso of=/dev/sdX bs=4M

⚠️ ASSET NAMING (CRITICAL - CASE SENSITIVE!)
═══════════════════════════════════════════════════════════════════

✅ CORRECT (will work):
  default.jpg      → Desktop wallpaper (lowercase, .jpg)
  splash.png       → Boot screen (lowercase, .png)
  startup.ogg      → Login sound (lowercase, .ogg)
  shutdown.ogg     → Logout sound (lowercase, .ogg)

❌ INCORRECT (will NOT work):
  Default.jpg      (capital D - Linux is case-sensitive!)
  wallpaper.jpg    (must be named "default.jpg")
  splash.PNG       (must be .png not .PNG)
  StartUp.ogg      (must be .ogg, lowercase)
  startup.mp3      (must be .ogg, not .mp3)
  Default.JPG      (must be lowercase .jpg)

🔧 SUPPORT & TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════

Common Issues:

Q: Build fails with "permission denied"
A: Run with sudo: sudo ./build_furryos_gen2.1_enhanced.sh

Q: Assets not appearing on boot
A: Check filenames (default.jpg, splash.png, startup.ogg) - must be lowercase!

Q: Can't create folders
A: Run: mkdir -p ~/FurryOS/sourcecode/payload/assets/{wallpapers,splash,sounds/{startup,shutdown}}

Q: Desktop shortcuts not working
A: Copy .desktop files to: ~/.local/share/applications/
   chmod +x ~/.local/share/applications/*.desktop

Q: Wallpaper won't change
A: Verify ~/FurryOS/sourcecode/payload/assets/wallpapers/default.jpg exists and is valid JPEG

Q: Mode switcher not responding
A: Try command-line: furryos-mode-switch normal
