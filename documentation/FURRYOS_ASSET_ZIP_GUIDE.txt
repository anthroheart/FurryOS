📦 PART 1: CREATING YOUR ASSET ZIP FILE
═══════════════════════════════════════════════════════════════════════════════

STEP 1: Create the exact folder structure for your ZIP
────────────────────────────────────────────────────────────────────────────────

Create this EXACT structure (case-sensitive!):

FurryOS_Gen2.1_Payload_Assets/
├── wallpapers/
│   └── default.jpg          ← Your desktop wallpaper (1920×1080+ JPEG)
├── splash/
│   └── splash.png           ← Your boot screen (1024×768 or 1920×1080 PNG)
└── sounds/
    ├── startup/
    │   └── startup.ogg      ← Login sound (2-5 seconds OGG Vorbis)
    └── shutdown/
        └── shutdown.ogg     ← Logout sound (2-5 seconds OGG Vorbis, optional)


COMMANDS TO CREATE THIS STRUCTURE:
────────────────────────────────────────────────────────────────────────────────

mkdir -p FurryOS_Gen2.1_Payload_Assets/wallpapers
mkdir -p FurryOS_Gen2.1_Payload_Assets/splash
mkdir -p FurryOS_Gen2.1_Payload_Assets/sounds/startup
mkdir -p FurryOS_Gen2.1_Payload_Assets/sounds/shutdown


STEP 2: Add your custom assets
────────────────────────────────────────────────────────────────────────────────

Copy your prepared assets (ALL LOWERCASE FILENAMES!):

# Wallpaper (REQUIRED)
cp /path/to/your/wallpaper.jpg FurryOS_Gen2.1_Payload_Assets/wallpapers/default.jpg

# Splash screen (REQUIRED)
cp /path/to/your/splash.png FurryOS_Gen2.1_Payload_Assets/splash/splash.png

# Startup sound (REQUIRED)
cp /path/to/your/startup.ogg FurryOS_Gen2.1_Payload_Assets/sounds/startup/startup.ogg

# Shutdown sound (OPTIONAL)
cp /path/to/your/shutdown.ogg FurryOS_Gen2.1_Payload_Assets/sounds/shutdown/shutdown.ogg


STEP 3: Create the ZIP file
────────────────────────────────────────────────────────────────────────────────

zip -r FurryOS_Gen2.1_Payload_Assets.zip FurryOS_Gen2.1_Payload_Assets/


STEP 4: Upload to your server
────────────────────────────────────────────────────────────────────────────────

Upload FurryOS_Gen2.1_Payload_Assets.zip to:
https://furry-os.org/assets/FurryOS_Gen2.1_Payload_Assets.zip

Make sure the file is publicly accessible!


═══════════════════════════════════════════════════════════════════════════════
🚀 PART 2: END USER INSTALLATION (AUTOMATED!)
═══════════════════════════════════════════════════════════════════════════════

STEP 1: Download the installer script
────────────────────────────────────────────────────────────────────────────────

wget https://furry-os.org/install_furryos_assets.sh
# OR
curl -O https://furry-os.org/install_furryos_assets.sh


STEP 2: Make it executable
────────────────────────────────────────────────────────────────────────────────

chmod +x install_furryos_assets.sh


STEP 3: Run the installer (as regular user, NOT sudo!)
────────────────────────────────────────────────────────────────────────────────

./install_furryos_assets.sh

The script will automatically:
  ✅ Download assets from https://furry-os.org/assets/FurryOS_Gen2.1_Payload_Assets.zip
  ✅ Create folder structure in ~/FurryOS/sourcecode/payload/assets/
  ✅ Extract and install all assets
  ✅ Verify assets are correct (format, size, duration)
  ✅ Create 5 desktop shortcuts (Applications menu + Desktop)
  ✅ Show summary and next steps

📋 END USER STEPS AFTER INSTALLATION
═══════════════════════════════════════════════════════════════════════════════

After running install_furryos_assets.sh, users should:

STEP 1: Copy build scripts to ~/FurryOS/sourcecode/
────────────────────────────────────────────────────────────────────────────────

cp GENOME_Gen2.1_Final.yaml ~/FurryOS/sourcecode/
cp build_furryos_gen2.1_enhanced.sh ~/FurryOS/sourcecode/
cp FurryOS_Live_Multimedia_Setup_Post_ISO_Gen2.1.sh ~/FurryOS/sourcecode/


STEP 2: Make build scripts executable
────────────────────────────────────────────────────────────────────────────────

chmod +x ~/FurryOS/sourcecode/*.sh


STEP 3: Build FurryOS
────────────────────────────────────────────────────────────────────────────────

cd ~/FurryOS/sourcecode
sudo ./build_furryos_gen2.1_enhanced.sh

Wait 15-30 minutes...


STEP 4: Find your custom ISO
────────────────────────────────────────────────────────────────────────────────

~/FurryOS/sourcecode/_generated/output/furryos-gen2.1-final-amd64.iso

✅ This ISO now includes YOUR custom wallpaper, splash, and sounds!

🎨 CUSTOMIZING ASSETS (FOR END USERS)
═══════════════════════════════════════════════════════════════════════════════

Users can customize assets BEFORE building:

METHOD 1: Use Desktop Shortcut
────────────────────────────────────────────────────────────────────────────────

2. Navigate to payload/assets/
3. Replace files:
   • wallpapers/default.jpg
   • splash/splash.png
   • sounds/startup/startup.ogg
   • sounds/shutdown/shutdown.ogg
4. Rebuild: cd ~/FurryOS/sourcecode && sudo ./build_furryos_gen2.1_enhanced.sh


METHOD 2: Command Line
────────────────────────────────────────────────────────────────────────────────

# Replace wallpaper
cp /path/to/new/wallpaper.jpg ~/FurryOS/sourcecode/payload/assets/wallpapers/default.jpg

# Replace splash
cp /path/to/new/splash.png ~/FurryOS/sourcecode/payload/assets/splash/splash.png

# Replace startup sound

# Rebuild
cd ~/FurryOS/sourcecode
sudo ./build_furryos_gen2.1_enhanced.sh

⚠️  CRITICAL REMINDERS
═══════════════════════════════════════════════════════════════════════════════

1. EXACT FILENAMES (case-sensitive!)
   ✅ default.jpg (not Default.jpg, wallpaper.jpg, desktop.jpg)
   ✅ splash.png (not Splash.png, splash.PNG, boot.png)
   ✅ startup.ogg (not StartUp.ogg, startup.mp3, login.ogg)
   ✅ shutdown.ogg (not Shutdown.ogg, shutdown.mp3)

2. EXACT FOLDER STRUCTURE IN ZIP
   FurryOS_Gen2.1_Payload_Assets/    ← Root folder name
   ├── wallpapers/                    ← Exact folder names
   ├── splash/
   └── sounds/
       ├── startup/
       └── shutdown/

3. CORRECT FILE FORMATS
   ✅ Wallpaper: JPEG (.jpg)
   ✅ Splash: PNG (.png)
   ✅ Sounds: OGG Vorbis (.ogg)

4. ASSET SPECIFICATIONS
   ✅ Wallpaper: 1920×1080+ pixels
   ✅ Splash: 1024×768 or 1920×1080 pixels
   ✅ Startup sound: 2-5 seconds
   ✅ Shutdown sound: 2-5 seconds (optional)

✨ COMPLETE END USER WORKFLOW
═══════════════════════════════════════════════════════════════════════════════

1. Download installer:
   wget https://furry-os.org/install_furryos_assets.sh

2. Make executable:
   chmod +x install_furryos_assets.sh

3. Run installer:
   ./install_furryos_assets.sh

   (Downloads assets, creates folders, installs everything, creates shortcuts)

4. Copy build scripts:
   cp GENOME*.yaml ~/FurryOS/sourcecode/
   cp build_furryos*.sh ~/FurryOS/sourcecode/
   cp FurryOS_Live*.sh ~/FurryOS/sourcecode/
   chmod +x ~/FurryOS/sourcecode/*.sh

5. Optional: Customize assets
   Click "FurryOS Source & Assets" → edit files in payload/assets/

6. Build:
   cd ~/FurryOS/sourcecode
   sudo ./build_furryos_gen2.1_enhanced.sh

7. Test:
   qemu-system-x86_64 -cdrom _generated/output/furryos-gen2.1-final-amd64.iso -m 2G

8. Deploy:
   sudo dd if=_generated/output/furryos-gen2.1-final-amd64.iso of=/dev/sdX bs=4M
