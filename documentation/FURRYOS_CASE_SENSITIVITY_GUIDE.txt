Short Answer: NO, not all files need lowercase - but there are important rules!

═══════════════════════════════════════════════════════════════════════════════
🎯 WHICH FILES **MUST** BE LOWERCASE (CRITICAL!)
═══════════════════════════════════════════════════════════════════════════════

Only these 3 core files MUST have EXACT lowercase names:

1. wallpapers/default.jpg          ← MUST be exactly "default.jpg"
2. splash/splash.png                ← MUST be exactly "splash.png"  
3. sounds/startup/startup.ogg       ← MUST be exactly "startup.ogg"
4. sounds/shutdown/shutdown.ogg     ← MUST be exactly "shutdown.ogg" (if used)

WHY? Because the build scripts look for these EXACT filenames!

✅ CORRECT:
   wallpapers/default.jpg
   splash/splash.png
   sounds/startup/startup.ogg

❌ WRONG (will break the build):
   wallpapers/Default.jpg          ← Capital D breaks it!
   wallpapers/DEFAULT.JPG          ← All caps breaks it!
   splash/Splash.png               ← Capital S breaks it!
   sounds/startup/StartUp.ogg      ← Capital letters break it!


═══════════════════════════════════════════════════════════════════════════════
🎵 YOUR 147 MP3S - CASE DOESN'T MATTER!
═══════════════════════════════════════════════════════════════════════════════

For your 147 music files, you can use ANY case you want!

✅ ALL OF THESE ARE FINE:
   music/Song Title.mp3
   music/SONG_TITLE.mp3
   music/song-title.mp3
   music/Song_Title_2024.mp3
   music/My Awesome Track (Remix).mp3
   music/01-Track-Name.mp3

Linux is case-sensitive, which means:
  • "Song.mp3" and "song.mp3" are DIFFERENT files
  • But both will work fine!
  • You can use whatever naming you prefer

BEST PRACTICES FOR 147 MP3S:
────────────────────────────────────────────────────────────────────────────────

✅ Use whatever naming convention you like:
   • "01 - Artist - Song Title.mp3"
   • "Song Title.mp3"
   • "artist-song-title.mp3"
   • Keep your original filenames!

✅ Spaces are OK:
   • "My Favorite Song.mp3" works fine

✅ Special characters are mostly OK:
   • Parentheses: "Song (Remix).mp3" ✅
   • Hyphens: "song-title.mp3" ✅
   • Underscores: "song_title.mp3" ✅
   • Numbers: "01-song.mp3" ✅

⚠️ AVOID (but they won't break anything):
   • Slashes: "/" (can't use in filenames)
   • Quotes: " or ' (can cause issues in scripts)
   • Backslashes: "\" (Windows path separator)

═══════════════════════════════════════════════════════════════════════════════
⚠️  IMPORTANT: LINUX IS CASE-SENSITIVE
═══════════════════════════════════════════════════════════════════════════════

On Linux (what FurryOS is based on):
  • "song.mp3" and "Song.mp3" are TWO DIFFERENT FILES
  • "Music/" and "music/" are TWO DIFFERENT FOLDERS

This is different from Windows/Mac where case doesn't matter.

PRACTICAL EXAMPLE:
────────────────────────────────────────────────────────────────────────────────

If you have:
  music/My Song.mp3

And you reference it as:
  music/my song.mp3        ← WRONG! Won't find it!

You MUST reference it exactly:
  music/My Song.mp3        ← CORRECT!
