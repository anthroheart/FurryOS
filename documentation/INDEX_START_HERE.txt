⚠️ CRITICAL: Asset Naming Rules
═══════════════════════════════════════════════════════════════════════════════

✅ CORRECT FILENAMES:
   default.jpg         ← Desktop wallpaper
   splash.png          ← Boot screen
   startup.ogg         ← Login sound
   shutdown.ogg        ← Logout sound

❌ WRONG FILENAMES (Will NOT work):
   Default.jpg         ← Capital D (Linux is case-sensitive!)
   wallpaper.jpg       ← Wrong name, must be "default.jpg"
   splash.PNG          ← Capital PNG extension
   splash.Png          ← Mixed case
   StartUp.ogg         ← Capital letters
   startup.mp3         ← Wrong format, must be .ogg
   startup.ogg.bak     ← Wrong name

🔴 REMEMBER: Linux filenames are CASE-SENSITIVE!
    "default.jpg" ≠ "Default.jpg" ≠ "DEFAULT.JPG"

📞 Troubleshooting
═══════════════════════════════════════════════════════════════════════════════

Problem: Assets not appearing on boot
Solution: Check filenames are lowercase (default.jpg not Default.jpg)

Problem: Build fails with permission error
Solution: Use sudo: sudo ./build_furryos_gen2.1_enhanced.sh

Problem: Can't create folders
Solution: mkdir -p ~/FurryOS/sourcecode/payload/assets/{wallpapers,splash,sounds/{startup,shutdown}}

Problem: Startup sound not playing
Solution: Verify file is OGG format (.ogg) not MP3 (.mp3)

Problem: Desktop shortcuts not appearing
Solution: Copy to ~/.local/share/applications/ and run: chmod +x *.desktop

See FurryOS_README.pdf and FURRYOS_FOLDER_STRUCTURE_GUIDE.txt for more help!
